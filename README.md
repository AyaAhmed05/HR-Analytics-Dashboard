
# Project Overview
This project is an HR Analytics dashboard built using Power BI to analyze employee data and generate insights related to attrition, demographics, and workforce distribution.

# Objectives
* Analyze employee attrition rate
* Understand workforce distribution by role, gender,Income, and experience
* Evaluate factors like travel frequency, overtime,job satisfication and promotions

# Data Preparation
* Cleaned and transformed raw HR data
* Created calculated columns for categorization
* Built multiple DAX measures

# Key Insights
* Higher attrition rate observed in Sales department while the lowest attrition rate is in research department
* Majority of employees travel rarely
* Most employees are in junior experience levels
* There are 183 employees due to promotion

# Conclusion
This dashboard helps HR teams make data-driven decisions to improve employee retention and workforce planning.
